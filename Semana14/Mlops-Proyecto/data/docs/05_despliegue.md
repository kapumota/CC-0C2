### Despliegue, contenedores y CI

El despliegue convierte una aplicación local en un servicio ejecutable de forma
reproducible. Docker permite empaquetar dependencias, código y configuración básica.

La integración continua ejecuta pruebas, lint, construcción de índice y evaluación
antes de aceptar cambios. Un workflow de CI reduce el riesgo de integrar código roto.

En un repositorio docente con varias semanas, el workflow debe limitarse a la carpeta
del proyecto usando rutas específicas y working-directory.
