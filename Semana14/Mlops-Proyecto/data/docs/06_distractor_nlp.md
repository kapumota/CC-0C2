### Tokenización y modelos de lenguaje

La tokenización divide texto en unidades procesables por un modelo. Los modelos de
lenguaje autoregresivos predicen el siguiente token usando el contexto previo.

La ventana de contexto limita la cantidad de información que puede procesar el modelo.
El ajuste fino permite adaptar un modelo preentrenado a instrucciones o tareas
específicas.

Este documento está relacionado con NLP, pero no describe el ciclo operativo de MLOps
ni los detalles de observabilidad o despliegue.
